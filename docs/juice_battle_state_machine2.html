Where each concept lives in the pipeline

Concept 1
σ and noise floor
GAME_READY: σ_live measured. Sets every threshold downstream. SETTLING: spread check uses σ. CALIBRATING: block avg gives σ_tare.
Concept 2
Stability detection
The state machine IS Concept 2. Slope + persistence = WAITING→POURING. Spread check = SETTLING→SETTLED.
Concept 3
Averaging + √N
CALIBRATING uses block avg (true √N, independent samples). Runtime uses EMA (low lag). Averaging fixes random noise — tare fixes offset.
Concept 4
Nonlinearity + multi-point cal
CALIBRATING builds the 3-point piecewise model + confidence score. STABLE_SETTLED applies it to every delta computation.
Concept 5
Mode-aware pipeline
The complete state machine. Concepts 1–4 are individual layers. Concept 5 is how they all plug into each other to produce glass counts from raw ADC counts.

Design Decisions locked in S002

Display unit
Glass count only
Production dashboard shows 🥛🥛🥛 count. No grams. No ml. Eliminates density conversion (juice ≠ water) and crowd-facing flicker simultaneously.
glass_volume_g
Operator-set, never hardcoded
Operator fills one glass, weighs it, enters value at game start. Default 150g (150ml glass). Hub sends it to both nodes via start_game(glass_volume_g=X).
Dual detection
Path A + Path B
Path A: slope-based real-time detection. Path B: baseline-jump detection for tap-force-masked pours. Volume accuracy is identical. Only difference: Path A enables live animation, Path B does not.
Tap force
Push-down taps contaminate slope
Hand weight on push-down tap transfers vertically into load cell, masking the pour slope. Path B handles this. Hardware recommendation: use side-lever (horizontal pivot) taps to avoid contamination entirely.
Dev vs production
Flicker is diagnostic
Development mode: show raw EMA weight in grams — flicker proves sensor is alive. Production mode: show glass count only — crowd sees stable integer. Single dashboard flag switches modes.
Hardware
10L glass jar · 150ml glass
Jar tare weight unknown — measured during calibration. Load cell: CZL601 40kg — handles jar tare + full 10L juice (≈10kg) with headroom. σ_live confirmed: 6.23g (office, fan on).
